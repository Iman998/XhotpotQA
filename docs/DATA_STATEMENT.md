# Data statement

XHotpotQA is a synthetic, translation-derived transformation of English HotpotQA. It covers
24 languages but does not constitute naturally authored information needs in those
languages. Wikipedia entities and cultural distribution remain English-centric. Automatic
translation can introduce artifacts, unequal quality, transliteration variation, and
answer leakage. Random language mixing is a controlled stress test, not a model of all
real multilingual information environments.

The resource must not be used to rank languages or speakers. Aggregate scores should be
accompanied by per-language, script, question-type, hop-role, and mismatch analyses.
Semantic evaluation and bilingual review are recommended when exact-match metrics disagree.
